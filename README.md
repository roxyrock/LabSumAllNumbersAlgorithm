# Sum All Numbers Algorithm #

This project implements a function named sumAll that calculates the sum of all integers between two given numbers, inclusive. 
The function accepts an array containing two values, determines the lower and higher number, 
and accumulates the total directly through iteration—without creating any intermediate arrays.

## Objective ##

The goal is to fulfill the user stories from the freeCodeCamp lab:
- sumAll accepts an array of two numbers.
- It returns the sum of both numbers plus all integers between them.
- The order of the numbers does not matter; the function handles both ascending and descending inputs.
